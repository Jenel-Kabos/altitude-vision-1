# Matrice effets de bord

| Action refusée | Statut/historique | Notification | Facture | Lock |
|---|---|---|---|---|
| Confirm | inchangé | aucune | aucune | aucun créé |
| Cancel | inchangé | aucune | n/a | aucun supprimé |
| Check-in | inchangé | aucune | n/a | inchangé |
| Check-out | inchangé | aucune | n/a | inchangé |
| No-show | inchangé | aucune | n/a | aucun supprimé |

Ces invariants sont vérifiés sur Mongo réel dans les deux sens A→B et B→A.
