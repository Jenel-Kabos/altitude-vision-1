## Point d'attention mobile — casse du rôle Proprietaire (à confirmer par l'agent mobile)

`altimmo-app/src/screens/Profil/ProfilScreen.jsx` compare `user?.role?.toLowerCase() === 'proprietaire'` — une comparaison **insensible à la casse construite manuellement**, alors que la valeur réelle stockée en base est `'Proprietaire'` (capitale). Ce n'est pas un bug en soi (le `.toLowerCase()` protège contre une divergence de casse), mais c'est un pattern **différent** de celui du backend/web (qui comparent la valeur exacte `'Proprietaire'`) — un drift de convention, pas un drift de comportement observé. À documenter dans `RBAC1_DUPLICATION_MATRIX.md`.

## Réponses directes (mandat §32, points 1-3, 18-20)

1. **Combien de rôles globaux existent réellement ?** 10 (enum `User.role`).
2. **Combien sont actifs ?** 8 — Admin, Collaborateur, Secretaire, GestionnaireImmobilier, CommunityManager, Communicant, Proprietaire, Client.
3. **Combien sont legacy (dormants) ?** 2 — User, Prestataire (présents dans le schéma et assignables, mais sans check d'autorisation fonctionnel dédié trouvé).
18. **Collaborateur est-il encore utilisé ?** Oui, activement (22 fichiers backend, assignable via `UsersPanel.jsx`) — mais son périmètre effectif est plus large que les rôles spécialisés, un héritage documenté comme volontaire dans le code lui-même.
19. **Prestataire ?** Assignable mais sans gate fonctionnel trouvé au-delà d'un tag CRM — LEGACY DORMANT.
20. **User ?** Assignable mais sans gate fonctionnel trouvé au-delà d'un filtre d'export groupé — LEGACY DORMANT.
