## Constat central

Le Financial Core (`FinancialPayment`/`PaymentAllocation`/`FinancialDocument`/`FinancialLedgerEntry`) n'est aujourd'hui **canonique que pour l'hôtel**. Tous les autres domaines (loyer, vente/location, visites, hébergement partiellement) restent sur leurs systèmes historiques, par décision explicite et documentée (ADR-FIN-007), pas par oubli. C'est un choix assumé de migration progressive contrôlée, pas une dette accidentelle — mais cela signifie que brancher un nouveau moyen de paiement (MTN direct, carte PSP) pour la vente ou le loyer **ne peut pas** aujourd'hui simplement "passer par le Financial Core" sans d'abord étendre son périmètre à ces domaines (roadmap PAY-6/PAY-7 proposée).
