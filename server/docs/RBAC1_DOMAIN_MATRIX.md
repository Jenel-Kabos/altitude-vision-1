## Notes de lecture

- **"OUI" sous Capability** = un `requireCapability(...)` réel est câblé sur au moins une route du domaine (vérifié par grep direct, pas supposé).
- Les domaines marqués "NON CONFIRMÉ" n'ont pas de check web/mobile identifié dans le temps imparti à cet audit — cela ne signifie pas une absence de contrôle (le backend reste toujours souverain), seulement qu'aucune UI-decision correspondante n'a été trouvée par les agents de recherche. À vérifier explicitement si RBAC-2 en a besoin.
- La colonne "Tenant" cite le mécanisme exact trouvé par domaine, jamais une supposition générique.
