## Légende verdicts

- **ACTIVE** : code fonctionnel, potentiellement en production.
- **LEGACY** : code présent, explicitement marqué comme non utilisé par les flux actuels dans le code lui-même.
- **PARTIAL** : fonctionnel dans un domaine, absent dans un autre (ex. MTN/Airtel : actif immobilier/visites, absent hôtel).
- **ABSENT** : aucun code, ne pas déduire une intégration à partir du seul nom du provider.
- **NON CONFIRMÉ** : affirmation qui ne peut être ni validée ni infirmée par le code actuel.

## Constat central

**CinetPay et YabetooPay sont déjà, aujourd'hui, les deux seuls agrégateurs Mobile Money réels du projet.** MTN et Airtel ne sont pas des intégrations à construire : ce sont déjà des opérateurs sélectionnables dans le flux Yabetoo existant (vente/location et visites). Le vrai travail futur pour "MTN"/"Airtel" au sens du mandat est donc soit (a) étendre l'usage de Yabetoo au domaine hôtel (actuellement en saisie manuelle uniquement), soit (b) évaluer une intégration directe opérateur si Yabetoo s'avère insuffisant — décision produit, non tranchée ici (§55 du mandat).
