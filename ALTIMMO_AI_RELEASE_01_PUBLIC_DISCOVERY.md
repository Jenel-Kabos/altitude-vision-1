# Découverte publique

## Parcours publié par le code

1. Accueil → bloc Assistant IA → page publique.
2. Altimmo → bloc Assistant IA → page publique.
3. Navigation Altimmo → entrée unique Assistant IA.
4. Mobile immobilier → carte Assistant immobilier IA → présentation ou expérience autorisée.

## États

| État | Mise en œuvre |
|---|---|
| Non présenté | retrait/non-livraison de la couche de présentation |
| Présentation publique | état par défaut de cette branche |
| Test interne | flags serveur + environnement + allowlist + coupe-circuit existants |
| Ouverture publique | non implémentée ; reste désactivée |

Aucune variable de présentation ne peut activer le fournisseur. L’autorité demeure exclusivement serveur.

Les exemples sont explicitement des formulations possibles, pas des résultats ni des annonces garanties. Le texte exclut réservation, paiement, garantie de disponibilité et conclusion de transaction.
